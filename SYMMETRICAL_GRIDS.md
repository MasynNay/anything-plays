# Symmetrical defaults

Every new console profile uses equally sized rectangular cells arranged with a horizontally symmetrical occupied footprint. GB/GBC: 3×3. GBA: 3×4 with the bottom center empty. SNES: 5×3 with the bottom outside cells empty. Use **Reset to symmetrical grid** to restore the current console's layout; existing customized saved profiles are deliberately preserved. Camera-preview dragging to draw zones is disabled until **Enable custom zone drawing** is checked. This is a source build and needs local UI/gameplay testing.
