# Anything Plays 3.1.0 — Scoped public redistribution decision

**Release engineering decision for the free, noncommercial, nonpromotional 3.1.0 desktop installer set.** This is an evidence-based distribution review following the approach already used for [the published 2.0.0 decision](RELEASE_DISTRIBUTION_REVIEW.md) and the public 3.0 packages. It is not a guarantee of copyright compliance in every jurisdiction or a license to use any separately restricted core commercially.

## Exact source and installers

The only proposed binaries are four unchanged, complete 18-console/11-core packages built on four native OSes from application source `104b96621ec4cb8dc39fde8c3fe96fc854c406ed`, which passed [13/13 same-source QA](https://github.com/MasynNay/anything-plays/actions/runs/43140637755). The original byte-preserving staging with SHA256 and native OpenCV source wheel fingerprints passed [43142249044](https://github.com/MasynNay/anything-plays/actions/runs/43142249044). The old private draft contains different stock-OpenCV binary bytes and must be replaced, not published unchanged.

Four authentic final package native dependency/notice audits passed [43147036559](https://github.com/MasynNay/anything-plays/actions/runs/43147036559). Every core family, package filename and original build remains version-pinned. The clean camera-only OpenCV wheels were source-built with FFmpeg disabled from the SHA-pinned 4.14.0.94 upstream source; [Windows patch/source instructions](V3_1_CLEAN_OPENCV_SOURCE_REPRODUCTION.md) are preserved. The 3.1 packaging does not include game ROMs, BIOS images, advertisements, donations or paid promotions.

## Carry-forward license decisions from prior public releases

- Anything Plays' original Python implementation and accompanying build instructions use the repository's MIT license. The MIT license does **not** relicense an emulator core or separately commissioned artwork.
- All 11 Libretro core families already shipped in published stable 3.0. The [3.0 original source release](https://github.com/MasynNay/anything-plays/releases/tag/v3.0.0-sources) preserves upstream source and license notice materials. Existing GNU GPL, MPL, LGPL, custom source and **Snes9x noncommercial** obligations continue. Distribute the complete binary free, noncommercially and without promotion; do not offer a commercial right to redistribute the complete package.
- SDL2 2.x and the bundled SDL extensions carry their own zlib-style terms, separate from the pygame-ce LGPL source terms. OpenCV's library is Apache-2.0 with MIT packaging scripts and source-specific downstream notices. Other native audio/font/image packages retain their own independent licenses.

## New pygame CE / mpg123 source and licensed-library obligations

The one newly introduced top-level runtime dependency compared with [stable 3.0 requirements](https://github.com/MasynNay/anything-plays/blob/v3.0.0/requirements.txt) is `pygame-ce>=2.5.8,<3` for optional controllers. The reviewed frozen wheel version is 2.5.8, under **LGPL-2.1-or-later**. The wheel bundles original SDL libraries and other independent native dependencies. The audited original frozen Linux/Mac runtime also contains shared `libmpg123`, separately covered by **LGPL 2.1**. The original final Linux binary contains the version string `1.33.7`, which matches the pinned original mpg123 source. Its local native filename, SHA fingerprint and original source SHA are [inventoried](V3_1_CLEAN_FINAL_NATIVE_INVENTORY.md); a string version check alone is not proof of bit-for-bit reproduced compilation.

An actual [seven-archive pygame/SDL/mpg123 original source package](https://github.com/MasynNay/anything-plays/actions/runs/43152661067), with full original LGPL notice and corresponding upstream licenses, passed a [read-only eight-asset publication preflight](https://github.com/MasynNay/anything-plays/actions/runs/43153670927). This exact SHA-pinned source companion is designed to be attached to the **same public 3.1.0 release page** as the installers. The original exact application source and build scripts remain directly available in GitHub. The [upstream mpg123 license notice](../licenses/mpg123-LGPL-2.1-ORIGINAL.txt) and [pygame LGPL notice](../licenses/Pygame-CE-LGPL-2.1.txt) are separately preserved, and the release notes prominently reference both.

GNU LGPL 2.1 Section 6 provides source/relinking routes for distributing executables with covered libraries; it does **not** require every user to own a controller or require that byte-for-byte deterministic builds be proven in advance. We provide original library source and original application's machine-readable source/build instructions, with same-place release asset access, to support modification/rebuild. The [recipient replacement guide](V3_1_LGPL_REBUILD_REPLACEMENT.md) documents exact package layout, development tools and native replacement paths on all four targets, including required ad-hoc re-signing of modified Mac app copies. Genuine user-modified `pygame.base` extensions were independently compiled from the tagged 2.5.8 upstream source, loaded and called from copies of exact original 3.1 binaries, then the frozen 18-console desktop launched successfully on [Linux](https://github.com/MasynNay/anything-plays/actions/runs/43148388829), [Windows](https://github.com/MasynNay/anything-plays/actions/runs/43149732092), [Apple Silicon and Intel Mac](https://github.com/MasynNay/anything-plays/actions/runs/43149191077).

**Important boundaries:** These successful replacement demonstrations cover `pygame.base`, not arbitrary ABI-compatible replacements of every pygame/SDL/mpg123/transitive native object. The original 3.1 distribution contains unmodified official pygame 2.5.8 wheel-native code; test modifications existed only in disposable copies and are not shipped. Source tag and upstream notice correspondence are documented, but no byte-for-byte reproducible build warranty is made for all third-party compiled objects. The supplied source/rebuild approach is reviewed for this free release scope, not a blanket future commercial-redistribution permission.

## Product QA, source publication and rollout

The owner explicitly requested the free public release multiple times with full notice that physical gamepad, camera and retail game tests remained incomplete. The [physical-device disclosure](V3_1_HARDWARE_QA_SCOPE.md) must accompany the release without changing `real_controller_hardware_acceptance.verified` to true. Installed native Tk/Stream Mode QA **did** pass 4/4, including preferences isolation. Actual real controller, live camera, save/audio/gameplay endurance are **not** certified for all four immutable final installers.

Publication procedure: use only the [gated original eight-asset stable workflow](../.github/workflows/v31-publish-cleared-clean-stable.yml). Its automation must authenticate private draft ID `442346875`, reject publication of old stock OpenCV bytes, verify exact source run hashes, append the source ZIP's SHA256 to the public `SHA256SUMS.txt`, and verify all eight uploaded assets' GitHub digests before making `v3.1.0` public. Public 3.0 and 3.1 RC2 must remain available. The prepared [release notes](V3_1_PUBLIC_RELEASE_NOTES.md) prominently state installer names, license restrictions, source locations and untested hardware limitations. The portfolio website must be updated after the release is verified, not before.

## Scope of engineering acceptance

The above evidence is a **scoped source availability, permission and executable replacement review** for these eight 3.1.0 release assets, adopting the same noncommercial distribution scope as the earlier public 2.0/3.0 packages while addressing the newly introduced LGPL dependencies. It is sufficient for an operator to decide to ship with these sources, notices and explicit known limitations, but is **not** an independent counsel opinion, a guarantee that every upstream native source can be deterministically reproduced, an approval for commercial bundling, or permission to suppress downstream LGPL rights. Any concrete missing source/notice information or reported library-replacement failure should be corrected promptly in release companion materials or a subsequent build.
