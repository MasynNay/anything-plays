# Contributing

Please open an issue describing a bug or proposed change before submitting a substantial pull request. Keep changes focused and preserve settings/profile compatibility. Run `python -m unittest discover -s tests -v` and `python -m compileall -q app.py cameras.py gba_emulator.py fetch_mgba_core.py`. Test camera, emulator and installers on the relevant target operating system. Do not commit ROMs, BIOS files, generated installers, native cores, or local preferences.
